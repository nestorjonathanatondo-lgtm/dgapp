# D&G Diésel & Gasolina — Sistema de Taller Mecánico 🚗

Sistema completo para gestión de taller mecánico: recepción vehicular, órdenes de servicio, diagrama de daños, checklist, facturación y más.

## 🚀 Cómo usarlo
Solo abre **index.html** en cualquier navegador o visita:
👉 https://tu-usuario.github.io/tu-repositorio/

## 📱 Instalar como App (APK)
1. Entra desde tu celular a la página
2. En el navegador: menú ⋮ → **"Instalar aplicación"**
3. ¡Listo! Queda como una app en tu celular

## ✅ Módulos
- 📊 Dashboard
- 📋 Recepción Vehicular con diagrama de daños
- 🗂️ Kanban de órdenes
- 💼 Facturación
- 📦 Inventario
- 👥 CRM y más
